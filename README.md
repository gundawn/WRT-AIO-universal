OpenWrt All In One Universal Script (OAIOUS)

OpenWrt All In One Universal Script (OAIOUS) — AIO-скрипт для автоматической первоначальной подготовки роутера на OpenWrt.

Скрипт в одном запуске выполняет обновление списков пакетов и установленного ПО, устанавливает или обновляет русскую локализацию LuCI, настраивает часовой пояс и синхронизацию времени, автоматически выбирает подходящий режим Flow Offloading в зависимости от платформы устройства, включает Packet Steering и Steering Flows 128, проверяет свободное место во Flash-памяти, устанавливает или обновляет NetShift, а также создаёт задачи Cron для ежедневной перезагрузки и автоматического обновления пакетов.

OAIOUS рассчитан не только на первоначальную установку, но и на повторный запуск: перед выполнением отдельных действий скрипт проверяет текущее состояние системы и наличие доступных обновлений.

⸻

🚀 Быстрая установка

Подключитесь к роутеру по SSH от имени root и выполните:

```sh
wget -O - https://raw.githubusercontent.com/gundawn/WRT-AIO-universal/main/install.sh | sh



Скрипт автоматически определяет используемый пакетный менеджер:

* apk
* opkg

Дополнительно проверяется:

* наличие установленных компонентов;
* наличие доступных обновлений;
* наличие русской локализации;
* текущие настройки сетевого ускорения;
* платформу устройства;
* свободное место в /overlay;
* наличие и актуальность компонентов NetShift;
* существующие задачи Cron.

Версия OpenWrt и архитектура пакетов отдельно не определяются, поскольку для работы AIO-скрипта достаточно напрямую определить используемый пакетный менеджер и платформу устройства.

⸻

⚙️ Что делает скрипт

1. 📦 Обновление списков пакетов

Сначала скрипт обновляет списки пакетов штатным пакетным менеджером системы.

Для apk используется:

apk update

Для opkg:

opkg update

Результат отображается в итоговом отчёте.

⸻

2. 🔄 Обновление установленных пакетов

После обновления списков выполняется обновление доступных пакетов.

Для apk используется:

apk upgrade --available

Для opkg скрипт получает список доступных обновлений:

opkg list-upgradable

и обновляет найденные пакеты по отдельности:

opkg upgrade <package>

Таким образом, обновление системы выполняется автоматически независимо от используемого пакетного менеджера.

⸻

3. 🇷🇺 Русская локализация

Скрипт проверяет пакет:

luci-i18n-base-ru

Возможны три варианта:

* пакет отсутствует → устанавливается;
* пакет установлен, но доступно обновление → обновляется;
* актуальная версия уже установлена → ничего не изменяется.

После проверки результат отображается в итоговом отчёте.

⸻

🕐 4. Часовой пояс и синхронизация времени

Скрипт проверяет текущие параметры OpenWrt и устанавливает:

Asia/Yekaterinburg
GMT+5

Используются параметры:

zonename = Asia/Yekaterinburg
timezone = +05

После этого проверяется наличие:

/etc/init.d/sysntpd

Если сервис присутствует, он включается и перезапускается для синхронизации времени.

В результате проверяется:

* установленный часовой пояс;
* установленное смещение времени;
* успешный запуск sysntpd.

⸻

⚡ 5. Сетевое ускорение

Скрипт автоматически определяет платформу устройства по данным:

/proc/device-tree/compatible

Ручного выбора Software или Hardware Flow Offloading не требуется.

Qualcomm / Qcom

Для платформ Qualcomm автоматически включается:

Software Flow Offloading

с параметрами:

flow_offloading = 1
flow_offloading_hw = 0

MediaTek / Filogic

Для платформ MediaTek / Filogic автоматически включается:

Hardware Flow Offloading

с параметрами:

flow_offloading = 0
flow_offloading_hw = 1

Таким образом, одновременно включается только один вариант Offloading.

Packet Steering

Дополнительно включается:

packet_steering = 2

Steering Flows

Устанавливается:

steering_flows = 128

После изменения конфигурация сохраняется через UCI.

Затем перезагружаются:

Firewall
Packet Steering

После этого значения повторно считываются из конфигурации и проверяются.

В итоговом отчёте сетевое ускорение получает отдельный статус.

⸻

💾 6. Проверка свободного места во Flash

Перед обработкой NetShift скрипт проверяет свободное место файловой системы:

/overlay

Проверяется именно свободное место, а не общий размер файловой системы.

Минимальный установленный порог:

20 MB

Свободно ≥ 20 MB

Скрипт продолжает обычную обработку NetShift.

Свободно < 20 MB

Установка или обновление NetShift пропускается.

При этом скрипт не прекращает выполнение полностью и продолжает остальные этапы:

* обновление списков пакетов;
* обновление пакетов;
* русская локализация;
* часовой пояс;
* синхронизация времени;
* сетевое ускорение;
* Cron.

В итоговом отчёте NetShift получает статус ошибки/пропуска в зависимости от результата выполнения.

Порог в 20 MB относится именно к свободному месту в /overlay.

⸻

🌐 7. NetShift

NetShift устанавливается и обновляется непосредственно через официальный установочный скрипт проекта NetShift.

Используется:

https://raw.githubusercontent.com/yandexru45/netshift/refs/heads/main/install.sh

Перед запуском установщика проверяется наличие следующих компонентов:

netshift
luci-app-netshift
luci-i18n-netshift-ru

Для каждого компонента определяется:

* установлен ли пакет;
* требуется ли ему обновление.

Если все необходимые компоненты уже установлены и актуальны, установщик NetShift повторно не запускается.

Если хотя бы один компонент отсутствует или требует обновления, запускается установщик NetShift.

Перед запуском проверяется наличие минимум:

20 MB

свободного места в /overlay.

Автоматические ответы установщику

После скачивания установочного скрипта OAIOUS автоматически передаёт ему необходимые ответы:

3
y

То есть ручное прохождение соответствующих вопросов во время AIO-установки не требуется.

Актуальный установщик NetShift самостоятельно выполняет необходимые действия, связанные с поддерживаемой версией sing-box extended.

OAIOUS не скачивает и не устанавливает sing-box самостоятельно.

⸻

🧩 8. Работа с временными файлами

Все временные файлы AIO-скрипта хранятся в:

/tmp/wrt-aio

В частности, туда временно сохраняется установщик NetShift.

После завершения работы скрипта каталог удаляется автоматически.

Для очистки используется trap, поэтому временные файлы AIO удаляются при завершении скрипта.

⸻

⏰ 9. Ежедневная перезагрузка

Скрипт проверяет системный Cron:

/etc/crontabs/root

и добавляет:

0 5 * * * /sbin/reboot

Таким образом, роутер автоматически перезагружается каждый день в:

05:00

Если такая строка уже присутствует, второй раз она не добавляется.

После изменения Cron скрипт включает и перезапускает службу:

/etc/init.d/cron

⸻

🔄 10. Автоматическое обновление пакетов

OAIOUS создаёт отдельную Cron-задачу для автоматического обновления пакетов.

Для apk

Используется:

0 */5 * * * apk update && apk upgrade

Задача выполняется один раз в пять часов:

00:00
05:00
10:00
15:00
20:00

и далее.

Для opkg

Используется:

0 */5 * * * opkg update && opkg list-upgradable | awk '{print $1}' | while read -r package; do [ -n "$package" ] && opkg upgrade "$package"; done

Сначала обновляются списки пакетов, затем автоматически обновляются все пакеты, для которых доступна новая версия.

Если соответствующая задача уже существует, дубликат не добавляется.

Таким образом, автоматическое обновление поддерживается как для apk, так и для opkg.

⸻

🔁 Повторный запуск

OAIOUS рассчитан на повторное выполнение.

При повторном запуске скрипт не устанавливает всё безусловно заново, а проверяет текущее состояние системы.

Проверяется:

* наличие русской локализации;
* наличие доступного обновления локализации;
* текущий часовой пояс;
* состояние sysntpd;
* платформа устройства;
* Flow Offloading;
* Packet Steering;
* Steering Flows;
* свободное место в /overlay;
* наличие компонентов NetShift;
* актуальность компонентов NetShift;
* наличие Cron-задачи перезагрузки;
* наличие Cron-задачи автоматического обновления пакетов.

Уже существующие корректные компоненты и Cron-задачи повторно не дублируются.

⸻

🌐 Загрузка файлов

Для скачивания установщика NetShift используется:

1. wget;
2. при отсутствии или неудаче wget — curl.

Сначала выполняется обычное HTTPS-подключение.

Если оно не проходит, предусмотрена повторная попытка с отключением проверки сертификата:

--no-check-certificate

для wget либо:

-k

для curl.

После скачивания файл проверяется на существование и ненулевой размер.

📋 Требования

Для запуска необходимы:

* роутер с OpenWrt;
* SSH-доступ;
* права root;
* рабочее интернет-соединение;
* пакетный менеджер apk или opkg.

Для установки или обновления NetShift требуется минимум:

20 MB

свободного места в /overlay.

Если свободного места недостаточно, скрипт не прекращает работу полностью, а пропускает обработку NetShift.

⚠️ Перед установкой

OAIOUS предназначен для автоматизации базовой подготовки OpenWrt.

Перед запуском следует учитывать уже существующую конфигурацию роутера, особенно если на нём настроены:

* DNS;
* DoH;
* DoT;
* VPN;
* Proxy;
* Firewall;
* собственные правила маршрутизации;
* sing-box;
* NetShift;
* другие сетевые сервисы.

Скрипт изменяет системные настройки OpenWrt, поэтому для уже настроенного роутера рекомендуется иметь резервную копию конфигурации.

⸻

🛠 После установки

AIO-скрипт выполняет базовую подготовку системы, но не пытается полностью настроить роутер под конкретного пользователя.

После завершения при необходимости самостоятельно настраиваются:

* беспроводные сети;
* SSID и пароли Wi-Fi;
* дополнительные параметры Wi-Fi;
* дополнительные сетевые параметры;
* NetShift;
* подписки NetShift;
* конфигурация sing-box;
* правила маршрутизации;
* другие пользовательские параметры.
